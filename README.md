## Deploy di Altare (gratis)

1. Buka console Altare → Create app → tab **GitHub**
2. Pilih repo ini (`Mamekmoen/info-airdrop-gratis`)
3. Altare mendeteksi Node.js otomatis, start command: `npm start`
4. Selesai — website online 24 jam di domain Altare
